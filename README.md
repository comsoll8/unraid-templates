# unraid-templates

Unraid Community Applications templates for [VYZN](https://github.com/comsoll8/vyzn), a self-hosted media server with an Android TV app.

- `vyzn.xml`: the Docker template (image: `ghcr.io/comsoll8/vyzn`, amd64 tested; arm64 experimental)
- `vyzn.png`: icon

To use before it appears in the store: Apps > Settings > Template Repositories > add `https://github.com/comsoll8/unraid-templates`.
